# 研究所求生記

一款以台灣學術界為背景的 roguelike 網頁小遊戲。你開開心心推甄上榜，接著要從碩士一路撐到博士、博後，目標是拿到教職。頭髮就是你的血條。

## 玩法

1. **擲屬性骰**：腦力、肝度、嘴砲、運氣，可以重骰。
2. **選領域**：資訊工程或生命科學（化學、物理敬請期待）。
3. **填推甄志願**：國立肝大、清蒸交大、不成功大、中央空調大學……錄取看擲骰。
4. **轉蛋抽指導教授**：SSR 佛系放養型、SR 八樓風很大型、R 凌晨三點 Line 你型……
5. **每學期選兩張卡**：寫論文、跟教授 meeting、投稿、去墾丁放空，部分行動要擲 d20。
6. **Boss 戰**：碩士口試、博士資格考、博士口試。
7. 精神、存款、教授好感任一歸零就提早下車。每局結束獲得「學術傷疤」，可以解鎖永久天賦。

共有 11 種結局等你收集。

## 執行

不需要安裝任何東西，用瀏覽器打開 `index.html` 就能玩。

- `grad-survival.html`：遊戲原始碼（Claude Artifact 格式，沒有 `<head>`）
- `index.html`：加上 `<!doctype html>` 與 viewport 的獨立版本，可直接部署到 GitHub Pages

修改 `grad-survival.html` 後，用下面的指令重新產生 `index.html`：

```bash
python build.py
```

進度（結局收集、傷疤、天賦）存在瀏覽器的 localStorage。
